============================================================
 CONECTAR EL BACKEND (LOGIN, PANEL Y SEGURIDAD) — GoDaddy
 SucreGas · Guía para la empresa o su equipo técnico
============================================================

La web ya está "lista para conectar": por defecto trabaja en
DEMO (guarda en el navegador). Con estos pasos pasa a usar una
base de datos REAL en el hosting de GoDaddy, con login, panel
del cliente y seguridad.

------------------------------------------------------------
 QUÉ TRAE LA CARPETA "05-Backend-PHP"
------------------------------------------------------------
  config.php   -> datos de la base de datos y correo
  db.php       -> conexión segura (no se edita)
  schema.sql   -> crea TODAS las tablas (usuarios, pedidos,
                  pagos, facturas, pqr, email_tokens,
                  recordar_tokens, intentos_login, auditoria)
  api.php      -> todas las acciones del servidor (con
                  seguridad: sesiones, CSRF, captcha, límites)

------------------------------------------------------------
 PASO 1 — Crear la base de datos en GoDaddy
------------------------------------------------------------
 1. GoDaddy > Hosting > Administrar > "Bases de datos MySQL".
 2. Crea una base de datos y un usuario con contraseña.
    Anota: NOMBRE_DE_BD, USUARIO_BD, CLAVE_BD.

------------------------------------------------------------
 PASO 2 — Subir la carpeta backend
------------------------------------------------------------
 - Sube el CONTENIDO de "05-Backend-PHP" a public_html con el
   nombre "backend". Resultado esperado:
     public_html/backend/config.php
     public_html/backend/db.php
     public_html/backend/api.php
     public_html/backend/schema.sql

------------------------------------------------------------
 PASO 3 — Configurar config.php
------------------------------------------------------------
 - Edita public_html/backend/config.php y pon tus datos:
      DB_NAME = 'TU_BASE_DE_DATOS'
      DB_USER = 'TU_USUARIO_BD'
      DB_PASS = 'TU_CLAVE_BD'
      SITE_URL = 'https://TU-DOMINIO.com'
      MAIL_FROM = 'no-reply@TU-DOMINIO.com'
   Guarda los cambios.

------------------------------------------------------------
 PASO 4 — Importar las tablas
------------------------------------------------------------
 - Abre phpMyAdmin, entra a tu base de datos, pestaña
   "Importar", selecciona backend/schema.sql y ejecuta.

------------------------------------------------------------
 PASO 5 — Activar el backend en la página (1 línea)
------------------------------------------------------------
 - Abre: assets/js/api.js
 - Busca al inicio:
      var cfg = { apiBase: "" };
 - Cámbialo a:
      var cfg = { apiBase: "/backend/" };
   Guarda y sube ese archivo (o toda la carpeta js).

------------------------------------------------------------
 PASO 6 — Probar
------------------------------------------------------------
 1. Entra al sitio > "Ingresar" > Crear cuenta
    (pide captcha; debe guardarse en la tabla "usuarios").
 2. Inicia sesión: verás el menú desplegable y el Panel (Mi panel).
 3. Intenta pedir gas sin sesión: debe exigir iniciar sesión.
 4. Haz un pedido, un pago y un reclamo con sesión: deben
    aparecer en el panel (Pedidos, Pagos, Reclamos, Historial).
 5. Prueba "Recuperar contraseña": si el hosting permite mail(),
    llega el enlace a cuenta.html?token=...
    Si GoDaddy bloquea mail(), configura SMTP en api.php
    (función enviar_correo).

------------------------------------------------------------
 SEGURIDAD YA INCLUIDA
------------------------------------------------------------
 - Contraseñas cifradas con password_hash (bcrypt/argon2).
 - Consultas preparadas (PDO) → evita inyección SQL.
 - Sesiones endurecidas: cookie HttpOnly/Secure/SameSite y
   regeneración del ID al iniciar sesión.
 - CSRF: token por sesión (cabecera X-CSRF) en acciones que
   modifican datos.
 - CAPTCHA propio en registro, login y recuperación.
 - Límite de intentos: bloqueo temporal tras 5 fallos.
 - Verificación de correo con token que expira.
 - Tokens de recuperación y "recordarme" guardados HASHEADOS.
 - Auditoría de eventos (login, logout, pagos, cambios).
 - Cabeceras de seguridad HTTP.
 - Al cambiar la contraseña se cierran las demás sesiones.

------------------------------------------------------------
 RECOMENDACIONES (mejoras futuras)
------------------------------------------------------------
 - Verificación de correo OBLIGATORIA antes de pagar.
 - Doble factor (2FA) por correo.
 - SMTP dedicado (ej. Gmail del negocio) para los correos.
 - Conectar facturación real (hoy las facturas son de ejemplo).
 - Copias de seguridad periódicas de la base de datos.
